# DeepFlow-HPC

GPU-accelerated fluid simulation with documented code, results, and presentation materials.

## Provenance

Ashutosh reports having built the original project. Original portfolio details are preserved in `original-project.json`. The controller family was ESP32, Arduino UNO and, for some experiments, Raspberry Pi. Exact historic wiring is no longer available.

Original repository recovered from https://github.com/ashupsingh/DeepFlow-HPC.git at commit `268be20dd0d0f36d66b7fac17de5a8b21bfd078d`, as a source snapshot. The recovered Git history remains in the local archive and is not republished here. Publication sanitization is described in PUBLICATION.md.

## Running the original

Start with the README and dependency manifests inside `recovered_original/`. Install dependencies in that folder only. This recovery does not certify runtime behavior or measured performance; see `EVIDENCE.md` and `VALIDATION.md`.
